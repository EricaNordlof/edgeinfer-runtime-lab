RELIABILITY

Failure → fallback

A simulated accelerator failure can be injected deliberately. The runtime detects it and switches to the CPU backend when fallback is enabled.

EDGEINFER_SIM_NPU_FAIL=1
sim-npu  ✕
   ↓
